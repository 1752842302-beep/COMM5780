Week 2 Reflection

1. What did I do?

This is my first time to creating my website.The workshop introduced two methods for building websites,named CampusPress and HTML/CSS.Finally I chose using HTML and CSS in Visual Studio Code to create my website because doing it this way offers a greater degree of freedom. I created an HTML file to organise the content of the web page, and also created an independent CSS file to control the appearance of the web page. I also uploaded all the files to GitHub and completed the publication of the website through GitHub Pages.

2. What did I learn?

I learnt the difference between HTML and CSS,HTML is the structure and CSS controls the visual appearance of the website. I realized that creating a website is not just typing the words what I want to say on the webpage,it also need to consider other things like how to navigate the visitors and how to plan a proper structure.

3. How does it connect to the reading or lecture?

Gillespie (2013) argues that algorithms are important because that they can determine which information can we see and considered relevant to each user.It means that the information we see online is one-sided.For example,when I use a search engine,the algorithm will determine the ranking of content ,which affects my understanding of the importance of content to some extent. This idea also connects to my workshop task.When I designing my website ,I had to decide how to organise information.What I want to emphasise?How should I better show my personality to visitors through the design of the website?This helped me reconize that digital experiences are shaped not only by the information itself,but also by the systems and structures through which it is presented.

4. What Does This Reveal About Digital Experiences?

Before this class,I always focus on the content of a website but ignore the structure behind it.However,now I visit a website,I can't help but observe their structure ,think about their underlying code ,how they attract website visitors ,and whether I can also use the same method on my website. Now my website is just a simple web page,and I can't wait to learn how to decorate it into a mature website.
