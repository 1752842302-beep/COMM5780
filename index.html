Week 2 Reflection

1. What did I do?

This is my first time to creating my website. The workshop introduced two methods for building websites, named CampusPress and HTML/CSS. Finally I chose using HTML and CSS in Visual Studio Code to create my website because doing it this way offers a greater degree of freedom. I created an HTML file to organise the content of the web page, and also created an independent CSS file to control the appearance of the web page. I also uploaded all the files to GitHub and completed the publication of the website through GitHub Pages.

2. What did I learn?

I learnt the difference between HTML and CSS. HTML is the structure and CSS controls the visual appearance of the website. I realized that creating a website is not just typing the words what I want to say on the webpage, it also needs to consider other things like how to navigate the visitors and how to plan a proper structure.

3. How does it connect to the reading or lecture?

Gillespie (2013) argues that algorithms are important because they can determine which information we see and consider relevant to each user. It means that the information we see online is one-sided. For example, when I use a search engine, the algorithm will determine the ranking of content, which affects my understanding of the importance of content to some extent. This idea also connects to my workshop task. When I was designing my website, I had to decide how to organise information. What do I want to emphasise? How should I better show my personality to visitors through the design of the website? This helped me recognise that digital experiences are shaped not only by the information itself, but also by the systems and structures through which it is presented.

4. What Does This Reveal About Digital Experiences?

Before this class, I always focused on the content of a website but ignored the structure behind it. However, now when I visit a website, I can't help but observe its structure, think about its underlying code, how it attracts visitors, and whether I can also use the same method on my website. Now my website is just a simple web page, and I can't wait to learn how to decorate it into a mature website.

Week 3 Reflection

1. What did I do?

I learned about web scraping this week. The workshop introduced tools such as Web Scraper.io and Python to collect information from webpages.

2. What did I learn?

Websites are not only places where people read, but also sources of digital data. Web scraping can help researchers collect and organise online information, making it easier to identify patterns and investigate digital media.

3. What are the limitations of web scraping?

I think it can only collect information that the tool can identify. If we encounter a website that prohibits web scraping, we may not be able to collect its data.
